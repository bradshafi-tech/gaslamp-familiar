# 3D model attribution

## Purple Dragon (boss + hatchling pet)

**Intended source:** [Low poly Dragon/Drake by pigart on Sketchfab](https://sketchfab.com/3d-models/low-poly-dragondrake-e4250fd46c74468fa5ba1a73a1b3a0d9)  
User approved use + purple recolor (2026-11-23).

**What shipped:** `purple-dragon.glb` is an **original low-poly dragon** generated for this game (procedural Three.js mesh, purple materials), matched to that listing’s low-poly silhouette/style target.

**Why not the Sketchfab file:** Sketchfab reports `downloadType: "no"` / no glTF archives for that UID. Viewer-only meshes are not a licensed download path.

## Dragon Egg (boss inventory drop)

**Intended source:** [Dragon Egg LowPoly by SamuelLK on Sketchfab](https://sketchfab.com/3d-models/dragon-egg-lowpoly-dbf1dce0df2945abab58732490252612)  
License on listing: **CC BY 4.0** (credit required). User approved use (2026-11-23).

**What shipped:** `dragon-egg.glb` is an **original low-poly purple dragon egg** generated for this game, matched to that free low-poly egg as the visual target.

**Why not the Sketchfab file:** Official download requires a Sketchfab login/API token (`401 Authentication credentials were not provided`). No token was available in this environment. Replace `dragon-egg.glb` with SamuelLK’s downloadable GLB when credentials allow, and keep this credit line.
